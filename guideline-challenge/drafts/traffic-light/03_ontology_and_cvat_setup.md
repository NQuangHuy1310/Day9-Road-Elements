# Bản nháp ontology CVAT — đèn giao thông cho xe cơ giới

**Version:** v1 (basic, thử trên ảnh tĩnh `data/data-image/`; chưa import/kiểm tra CVAT). Chỉ áp dụng cùng `02_guideline.md` và `03_cvat_labels.json` trong thư mục nháp này; **không** thay thế các file `project/03_*`. Giữ nguyên schema CVAT đã có, v1 ưu tiên nhãn màu và chỉ điền các field khác theo bằng chứng nhìn thấy.

| CVAT label/attribute  | Kiểu               | Allowed values (ngoài placeholder)                                 | Default         | Quy tắc                                                                                                                                     |
| --------------------- | ------------------ | ------------------------------------------------------------------ | --------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| `vehicle_signal_head` | Class rectangle    | Một vỏ đầu đèn xe cơ giới / bbox                                   | —               | Một đầu độc lập, ôm phần vỏ thấy được; không gồm bộ đếm/cột.                                                                                |
| `signal_form`         | Select trên bbox   | `circular`, `arrow`, `unknown`                                     | `__undefined__` | Chọn theo dạng chỉ thị nhìn rõ, không rõ thì `unknown`.                                                                                     |
| `display`             | Select trên bbox   | `red`, `yellow`, `green`, `unlit`, `unknown`                       | `__undefined__` | Màu đang sáng trong ảnh; `unlit` chỉ khi thấy rõ mọi bóng đều không sáng; không chắc thì `unknown`. Không suy lỗi.                          |
| `arrow_direction`     | Select trên bbox   | `left`, `straight`, `right`, `u_turn`, `unknown`, `not_applicable` | `__undefined__` | `circular` → `not_applicable`; mũi tên rõ → hướng nhìn thấy; còn lại → `unknown`.                                                           |
| `ego_applicability`   | Select trên bbox   | `applies`, `does_not_apply`, `unknown`                             | `__undefined__` | V1 chọn `unknown` khi thiếu bằng chứng lane mapping; không suy quyền được đi từ màu. Chỉ chọn giá trị khác khi thấy rõ quan hệ với làn ego. |
| `needs_review`        | Select trên bbox   | `yes`, `no`                                                        | `__undefined__` | `no` nếu bình thường; `yes` khi object cần reviewer phân xử.                                                                                |
| `image_escalate`      | Class tag trên ảnh | Có hoặc không                                                      | Không có tag    | Ca chưa rõ scope, khó phân biệt vỏ hoặc ngoài rule; reviewer cần xem thêm.                                                                  |

Dùng CVAT Shape rectangle cho từng JPEG, điền **mọi select** trên mỗi bbox. `__undefined__` là chưa trả lời, không để lại trong annotation hoàn tất; `unknown` là quyết định có chủ ý. Với ca cần review: gắn `image_escalate`; nếu có bbox thì đặt thêm `needs_review=yes`, nếu chưa chắc có nên vẽ bbox thì chỉ gắn tag ảnh. Ghi tên file + vị trí/miêu tả object cần kiểm ngoài export để reviewer biết mục tiêu review. Tag/`unlit` không có nghĩa đèn hỏng. Không gán sự kiện chuyển pha/nhấp nháy từ ảnh tĩnh.

**Chưa xác nhận:** chưa đăng ký `data-image` vào catalog/sample pack, chưa đo tolerance geometry bằng calibration, chưa import Raw JSON hoặc kiểm export XML CVAT thực. Chỉ nâng v2 sau khi thử và thống nhất các ca bất đồng.
